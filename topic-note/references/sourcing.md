# Sourcing

How research happens and how claims get attributed.

## Research execution

- Dispatch one background agent to research the sub-topics in parallel, so the conversation keeps flowing while it reads.
- Follow every claim back to the source that owns it.

## Source priority

- Primary sources first: official docs, source code, specs, first-party APIs.
- Secondary write-ups only where they explain a primary source better — never instead of one.
- Never write from parametric knowledge: a substantive claim must come from a retrieved source, not the model's memory. Memory may organise the material, not supply it.

## Sufficiency

Research is done when every planned sub-topic has at least one sourced claim. Collect the sources as you go — the final document needs them.

## Attribution

- In the body: name the source alongside the claim (lightweight, e.g. "per <source>").
- At the end: a `Sources` section listing every source referenced, with links where they exist.
