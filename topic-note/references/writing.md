# Writing

## Intuition first

Order matters: intuition → analogy → definition → example → confirmation. Never open a concept with its formula.

## Analogies

Every hard concept earns one analogy. Prefer a comparison the reader already knows over an invented metaphor.

## Examples

Every concept gets at least one concrete example.

## Comparisons

When two things are similar, compare them immediately — a table beats prose for this.

## Format

- Standard Markdown only — the document renders cleanly in any viewer (VS Code, GitHub, Obsidian).
- Mermaid diagrams (fenced ```mermaid blocks) and tables are welcome.

## Length

No hard limit. Cover the topic completely; long documents stay organised with headings and a contents list. Never split into multiple files.

## Language

Write in the user's language.
